# ✈️ Sky Hub Tycoon

A mobile airport management / idle tycoon game. Runs in any phone browser — no install needed.

## How to play
Passengers flow through your airport: **Check-in → Security → Departure Lounge → Gates → ✈️**

- Every flight that departs pays you per passenger on board.
- Find the **⚠️ BOTTLENECK** and fix it: build more desks/lanes/gates or upgrade them.
- Keep passengers happy (short queues, clean terminal, shops) to earn **⭐ reputation**.
- Reputation unlocks bigger airlines and better upgrades.
- Tap **👆 Help** buttons to personally speed things up during rushes.
- React to random events (VIPs, storms, inspections, strikes…) — your choices matter.
- Catch the golden **bonus planes** flying across the screen.
- Your airport keeps earning while you're away (offline earnings).

## Run it
Open `index.html` in a browser. That's it.
